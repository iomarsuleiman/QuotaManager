## Local test instance

URL: http://127.0.0.1:8080
Initial password: `admin`

Run with `.venv/Scripts/python scripts/run_local.py --port 8080` on Windows,
or `.venv/bin/python scripts/run_local.py --port 8080` on Linux.
Stop the foreground runner with Ctrl+C. The instance started during this work
runs in a hidden process; its logs are in data/local-test/server.*.log.
Its database and shared files are isolated below data/local-test.
DHCP, packet forwarding, speed shaping and VPN networking are not started.
